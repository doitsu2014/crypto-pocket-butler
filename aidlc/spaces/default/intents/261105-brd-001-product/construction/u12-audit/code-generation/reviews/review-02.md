### Summary

The service is well structured and the unit tests, formatting, clippy and boundary gate all pass, but the retention credential has no `DELETE` grant on `append_idempotency`, so every production sweep will be recorded as failed, and the append endpoint requires inputs the shared contract does not define. Those two items need fixing before a developer or an emitting-team can build against this unit with confidence.
