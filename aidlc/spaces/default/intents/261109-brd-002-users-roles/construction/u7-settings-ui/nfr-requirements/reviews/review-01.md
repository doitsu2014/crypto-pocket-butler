### Summary

The three blocking findings are all cross-artifact rather than stylistic: the bypass bound NFR24.2 asserts is narrower than the code, the retry and 15 s deadline rules cannot both be implemented as written (and neither matches the existing query client), and the D1 "404 as null" path needs a pinned problem type that Identity does not emit. The minors are precision fixes — a false rate-limit precedent, the omitted export-id route, an overbroad "no third-party origin" claim, an incomplete profile field list, and a cache-key mismatch — that a developer could otherwise carry as unstated assumptions.
