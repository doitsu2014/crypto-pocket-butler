### Summary

The design is disciplined, honestly sourced and correctly scoped for a UI unit, but its central recovery path rests on an identifier comparison that can never match (internal Identity user id against the Supabase auth id), and the S2 route it depends on exists in no contract and in no code. Fix the adoption rule and pin S2 before Code Generation; the remaining findings are small precision issues.
