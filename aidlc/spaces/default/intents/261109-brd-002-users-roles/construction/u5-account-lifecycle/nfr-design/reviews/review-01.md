### Summary

The tombstone idea is right, but nothing in the design reads the column it adds, so a deleted account's still-valid token currently provisions a fresh account, and the restore-versus-sweep race is not serialised at all: the lease is written but never consulted, and the anonymise update has no status guard. Both fail security rules the unit claims to satisfy and need design changes before implementation.
