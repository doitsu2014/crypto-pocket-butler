### Summary

The transport handling, deadline/retry policy, and screen state machine are careful, but the no-record path — the primary first-visit journey — is misimplemented: every acceptance is rendered pre-checked and unassertable. Three further cross-unit and routing edges (recorded-consent payloads, the unpinned no-record answer, and the U7 destination loop) need resolving before the unit is ready.
