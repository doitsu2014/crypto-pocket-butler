### Summary

The main concern is security: NFR10.1 relieves Identity of validating the Supabase JWT, which both contradicts a hard project mandate and leaves the principal-resolution endpoint that supplies role and status to the whole system unauthenticated. Behind it sit a set of traceability and coherence defects (colliding derived IDs, an undecided source for the MFA-with-credentials fact, and no reclamation rule for a worker that dies mid-request) that should be fixed before this NFR set is used to drive Code Generation.
