# Organisation Memory

Standing rules that apply to every project this organisation builds. Edit this
file to change behaviour across all intents and spaces.

## Engineering Standards

- All code changes are reviewed by a human before merge.
- Every requirement has a testable acceptance criterion.
- Secrets never appear in source or logs.

## Security and Compliance

- Least privilege for all credentials and service accounts.
- Dependency changes are recorded and reviewed.

## Walking Skeleton

Scope-dependent. Greenfield work starts with the thinnest end-to-end slice.

## Testing Posture

Standard: requirement-driven tests with a happy-path floor per component.
