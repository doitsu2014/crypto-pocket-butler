### Summary

The crate boundaries are clean (domain has no framework dependency, application imports neither infrastructure nor http, DTOs stay in http) and decimals are used throughout, but the unit is NOT-READY on correctness: an OKX credential loses its passphrase on the primary add path, the Vault adapter depends on grants nothing provisions, the lease is never renewed and the snapshot fence compares against the sync's start time rather than the write time, the C3 support-grant branch is missing, and the CSV import and wallet-token paths cannot produce their intended data. Validation: `cargo test -p account-domain -p account-application -p account-infrastructure -p account-http` exits 0 (63 domain, 69 application, 5 provider, and 24 http tests pass; the 13 repository tests are `#[ignore]`d for lack of a disposable Postgres).
