### Summary

The structural skeleton is sound — three source-of-truth artifacts agree, every rule ID resolves, and all assigned acceptance criteria are present — but the first-authentication workflow never defines how a provisioned `pending` user becomes `active`, and the profile-override rule has no stored marker to consult. Fix the pending-to-active path and the profile override representation, correct the AC1.4.2 and admin-search coverage, and the unit is implementable.
